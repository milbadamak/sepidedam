## صوت و تلاوت

| | چهار قل | دعای گشایش |
|---|---|---|
| خواننده | مشاری راشد العفاسی (مرتّل) | `ar-IQ-BasselNeural` — مرد، آرام و مهربان |
| سرعت | عادی | **‎−۱۸٪** (آهسته، برای حضور قلب) |
| کیفیت | ۶۴ کیلوبیت | ۴۸ کیلوبیت |
| حجم | ۱٫۰ مگابایت (۲۲ فایل) | ۳۲۵ کیلوبایت (۱۳ فایل) |
| مکث بین بخش‌ها | ۳۲۰ میلی‌ثانیه | **۷۸۰ میلی‌ثانیه** |
| نغمهٔ پس‌زمینه | ندارد (صدای قاری جای نغمه ندارد) | **دارد، تولید زنده** |

**همه‌چیز کاملاً آفلاین است.** بدون اینترنت هم پخش می‌شود.

### نحوهٔ پخش
دکمهٔ **♪ بشنو** روی هر کارت:

1. برای سوره‌ها: اول **بسم‌الله**، سپس آیه‌ها به ترتیب با مکث کوتاه
2. برای دعا: مستقیم از بخش اول، با مکث بلندتر و نغمه
3. خطِ در حال خواندن با **کادر طلایی** متمایز می‌شود
4. زیر دکمه نوشته می‌شود: «در حال تلاوت آیهٔ ۳ از ۵» یا «در حال خواندن بخش ۳»

| کنترل | کار |
|---|---|
| **♪ بشنو** | شروع از اول |
| **♪ از اول** (همان دکمه، حین پخش) | برگشت به اول |
| **■ قطع** | توقف فوری |
| **نغمهٔ پس‌زمینه: روشن/خاموش** | فقط روی کارت دعا |

فقط یک کارت در هر لحظه پخش می‌شود؛ اگر کارت دیگری را بزنی، قبلی قطع و جدید از اول شروع می‌شود.

> شمارندهٔ `+` و `−` از پخش صوت جداست. گوش دادن و شمردن دو کار جدا می‌مانند تا خودت انتخاب کنی کِی چه کار کنی.

## نغمهٔ پس‌زمینهٔ دعا

یک **پدِ بمِ کشیده** با نفسِ آهسته، **زنگ‌های پراکنده و دور**، و اکویی که خودش ساخته می‌شود.

**هیچ فایل صوتی‌ای وجود ندارد.** همه‌چیز با Web Audio API *زنده* در مرورگر ساخته می‌شود. یعنی:

| | |
|---|---|
| حجم | **صفر** — چند کیلوبایت کد |
| تکرار | بی‌نهایت، بدون درز و بدون قطعهٔ تکراری |
| مجوز | ندارد، چون فایلی در کار نیست |
| کنترل | با `RATE`، `CHIME_SCALE` و `bedFade` تنظیم می‌شود |

میزان صدا عمداً خیلی پایین است (حدود ‎−۴۰ دسی‌بل، `RMS ≈ 0.01`) تا هرگز روی صدای دعا نیفتد. آرام بالا می‌آید (۳٫۵ ثانیه) و آرام محو می‌شود (۲٫۲ ثانیه).

اگر تب برنامه را عوض کنی، نغمه هم می‌خوابد و وقتی برگردی آرام برمی‌گردد.

**زیر سوره‌ها نمی‌آید** — چون صدای قاری جای نغمه ندارد.

### دربارهٔ صدای دعا — یک صداقت
«دعای گشایش» یک متن واحد با سندِ خاص نیست؛ **چند آیه و حدیث شناخته‌شده به‌هم چسبیده‌اند**. بنابراین:
- صوت **مصوّب و رسمی** برای کلِ آن وجود ندارد
- بخش‌های قرآنی‌اش (یونس ۲۱:۸۷ و بقره ۲:۲۸۶) صوت رسمی دارند، بقیه (مناجات شعبان، دعای حفظ از بلا، پناه از فقر و قبر) سنت‌اند و صوتی ندارند
- پس صدایش **ماشینی** است و **بدون اعراب** (موتور TTS با اعراب کامل به‌هم می‌ریزد)

برای همین در کارت دعا این را صریح نوشته‌ایم. اگر صدای مصوّب خواستی، دو راه داری: صدای خودت را ضبط کن، یا متن را به دو بخش قرآنیِ صوت‌دار بشکن.

### ساختار فایل‌های صوتی
صوت‌ها **خط‌به‌خط** هستند تا بتوان دقیقاً خطِ در حال خواندن را هایلایت کرد (بدون نیاز به فایل زمان‌بندی).

```
audio/
  bismillah.mp3          ← بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ
  109-1.mp3 … 109-6.mp3  ← کافرون (هر آیه یک فایل)
  112-1.mp3 … 112-4.mp3  ← اخلاص
  113-1.mp3 … 113-5.mp3  ← فلق
  114-1.mp3 … 114-6.mp3  ← ناس
  dua-1.mp3 … dua-13.mp3  ← دعای گشایش (هر بخش یک فایل)
```

الگو: `audio/{شماره سوره}-{شماره آیه}.mp3` و `audio/dua-{شماره بخش}.mp3`

## ساخت دوبارهٔ صوت دعا

اگر خواستی صدا یا سرعت دعا را عوض کنی:

```bash
node tools/make-dua-audio.mjs            # خودکار
node tools/make-dua-audio.mjs --edge     # فقط موتور عصبی (کیفیت بهتر)
node tools/make-dua-audio.mjs --google   # فقط Google TTS
```

**بدون هیچ نصبی** — Node ۲۲ به بالا کافی است (بستهٔ npm لازم نیست).

صداهای عربی موجود برای `VOICE`:
`ar-IQ-BasselNeural` · `ar-SY-LaithNeural` · `ar-EG-ShakirNeural` · `ar-EG-SalmaNeural` · `ar-SA-HamedNeural` · `ar-LB-RamiNeural` و ۲۶ صدای دیگر.

> `tools/ws.mjs` یک کلاینت WebSocket کوچک روی TLS خام است، چون کتابخانهٔ `WebSocket` داخلی Node اجازهٔ ست‌کردن هدرهای لازم (Origin، Cookie، User-Agent) را نمی‌دهد و سرویس بدون آن‌ها ۴۰۳ می‌دهد.

## دربارهٔ «دعای گشایش»
این متن یک دعای واحد با سندِ خاص نیست؛ **جمعی از آیات و ادعیهٔ شناخته‌شدهٔ قرآن و سنت** است، کنار هم چیده شده تا یک مناجات کوتاه و پرقدرت برای لحظه‌های سخت بسازد:

- «اللَّهُمَّ إِنِّي كُنْتُ أَعُوذُ بِكَ مِنَ الْهَمِّ وَالْحَزَنِ» — مناجات شعبان
- «فَارْحَمْنِي بِمَا صَنَعْتَ إِلَيَّ» — همان مناجات
- «لَا إِلَٰهَ إِلَّا أَنْتَ سُبْحَانَكَ إِنِّي كُنْتُ مِنَ الظَّالِمِينَ» — دعاءٔ یونس، سنتِ پاسخ به هر سختی
- «رَبَّنَا لَا تُؤَاخِذْنَا إِن نَّسِينَا أَوْ أَخْطَأْنَا…» — آیهٔ ۲۸۶ بقره
- «أَنْتَ الْمَوْلَىٰ فَأَنْصُرْنَا وَأَنْتَ النَّصِيرُ» — آخر آیهٔ ۲۸۶ بقره

متن‌های قرآنی (چهار قل) عیناً از مصحف نقل شده‌اند. ترجمه‌ها ادبی و به زبان فارسی معاصر نوشته شده‌اند.

## ساختار

```
index.html            ← کل برنامه (HTML + CSS + JS در یک فایل)
data.json             ← نسخهٔ داده‌خوانِ همین محتوا (مرجع و برای ویرایش آسان)
manifest.webmanifest  ← تنظیمات PWA
sw.js                 ← Service Worker و کش آفلاین (شامل صوت‌ها)
icon.svg              ← آیکون
audio/                ← ۳۵ فایل صوتی آفلاین
tools/                ← اسکریپت ساخت صوت دعا (اختیاری، اجباری نیست)
README.md
```

`index.html` محتوا را داخل خودش دارد؛ `data.json` مرجع موازی است. اگر خواستی از `data.json` بخوانی، آرایهٔ `ITEMS` را در `<script>` با `fetch('data.json')` جایگزین کن.

اگر صوت جدیدی خواستی اضافه کنی: فایل را در `audio/` بگذار، شماره‌اش را در `ITEMS` اضافه کن، و الگوی نام‌گذاری را رعایت کن.
